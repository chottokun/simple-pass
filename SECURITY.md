# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **SimplePASS**, please report it responsibly.

- **Do NOT create a public GitHub Issue** for security vulnerabilities.
- Please report security concerns via a private message or email to the repository owner.
- Please include steps to reproduce the issue, along with any relevant details regarding your system environment.

We aim to acknowledge receipt of security reports within 48 hours and provide updates regarding fixes in a timely manner.
